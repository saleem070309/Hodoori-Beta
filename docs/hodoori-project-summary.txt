مشروع "حضوري" (Hodoori) - الملخص الكامل والتقنيات المستخدمة
=====================================================

1. ملخص المشروع ومكوناته الرئيسية
----------------------------------
مشروع "حضوري" هو نظام ذكي وشامل لإدارة الحضور والغياب في المدارس والمؤسسات التعليمية، مصمم ليعمل كـ "تطبيق ويب تقدمي" (Progressive Web App - PWA) يدعم العمل أوفلاين (Offline-First) مع تعزيزه بآليات الذكاء الاصطناعي، التعرف على الوجوه، والتكامل التفاعلي مع مختلف أطراف العملية التعليمية.

يهدف النظام إلى أتمتة وتسريع عملية تحضير الطلاب وتقليل الجهد الإداري وتسهيل المتابعة الفورية لأولياء الأمور والمعلمين والوزارة.

البوابات وواجهات المستخدم (Portals):
1. لوحة الإدارة (Admin Dashboard):
   - إدارة الطلاب، المعلمين، الفصول، وأجهزة البصمة/التحضير.
   - إدارة وتصدير التقارير الشاملة وإعدادات الذكاء الاصطناعي والإشعارات.

2. لوحة المعلم (Teacher Dashboard):
   - التحضير السريع (يدوياً، بالرمز QR Code، أو عبر التعرف الرقمي على الوجه Face API).
   - عرض حصص اليوم وإحصائيات الطلاب وسجلات الحضور والغياب.

3. لوحة الوزارة/الإشراف (Ministry Dashboard):
   - متابعة مؤشرات الأداء العامة، النسبة الإقليمية/المحلية للحضور والغياب، والإحصائيات الشاملة.

4. بوابة الطالب (Student Portal):
   - عرض نسبة حضور الطالب، أيام الحضور والغياب، بطاقة الطالب الرقمية، والإشعارات الخاصة به.

5. بوابة ولي الأمر (Parent Portal):
   - متابعة الأبناء المسجلين، تلقي إشعارات الحضور والغياب التلقائية، وتقديم الأعذار أو الطلبات.

6. الصفحة الرئيسية والتعريفية (Main Index):
   - الصفحة العامة للنظام والدخول الموحد للأنظمة المختلفة.


2. التقنيات والحلول المستخدمة في المشروع
----------------------------------------
تم بناء المشروع باستخدام بنية تقنية حديثة وموثوقة خفيفة الوزن وخالية من التعقيدات الخارجية لتضمن السرعة والأداء العالي:

أولاً: تقنيات الواجهة الأمامية (Frontend & UI):
- اللغات الأساسية: HTML5 و CSS3 و Vanilla JavaScript (JS حديث بدون أطر عمل ثقيلة لضمان السرعة والتكامل).
- تصميم الواجهات والجماليات:
  * شبكة تصميم مرنة ومستجيبة (Responsive UI / Dark & Light Themes).
  * أيقونات وتقنيات مرئية حديثة عبر مكتبات متكاملة مثل FontAwesome و Boxicons و Lucide Icons.
  * مكتبات عرض البيانات والرسوم البيانية: Chart.js لعرض الإحصائيات والتطويرات البيانية للحضور.
- التشغيل كتطبيق تقدمي (PWA - Progressive Web App):
  * دعم ملف manifest.json لإمكانية تثبيت النظام على الهواتف والأجهزة الذكية كتطبيق مستقل.
  * دعم التخزين المحلي والعمل دون اتصال بالإنترنت (Offline Storage).

ثانياً: الذكاء الاصطناعي والمعالجة الذكية (AI & Machine Learning):
- المساعد الذكي (AI Agent):
  * مساعد إداري ذكي مدمج يعتمد على نماذج الذكاء الاصطناعي (مثل OpenRouter / Gemini API).
  * قادر على تنفيذ الأوامر الإدارية تلقائياً، إجراء استعلامات عن البيانات، وإنشاء وتصدير التقارير (Excel/Word)، وإرسال الرسائل والإشعارات.
- التعرف على الوجوه (Face Recognition):
  * الاعتماد على مكتبة Face-API.js لمعالجة الصور واستخراج البصمة الوجهية الرقمية للطلاب لتسجيل الحضور آلياً عبر الكاميرا.

ثالثاً: إدارة البيانات والتخزين (Data & Storage Engine):
- قاعدة البيانات المحلية (Core DB):
  * محرك بيانات محلي يعتمد على IndexedDB و LocalStorage لتوفير أداء فائق وسرعة استجابة دون الحاجة لخادم عالي التكلفة في مرحلة التجربة/البيتا.
- المصادقة والأمان (Core Auth):
  * نظام مصادقة وحفظ جلسات المستخدمين بمختلف الأدوار (مدير، معلم، طالب، ولي أمر، وزارة).

رابعاً: التكامل والخدمات الخارجية (Integrations & Utilities):
- تصدير واستخراج التقارير:
  * دعم تصدير واستيراد ملفات Excel باستخدام مكتبة XLSX (SheetJS).
  * دعم تصدير واستخراج ملفات Word / PDF المنسقة رسمياً.
- خدمات البريد والإشعارات:
  * Gmail API / Email Integration: لإرسال التقارير والرسائل عبر البريد الإلكتروني.
  * Web Push Notifications: لتنبيه أولياء الأمور والإدارة بالغياب أو التحديثات المباشرة على أجهزتهم.
